# Desarrollo

El proyecto está desarrollado en C++ y utiliza SFML para la ventana, los
gráficos, el audio y la interacción básica.

El código fuente se encuentra en `src/`, las cabeceras en `include/` y el
ejecutable generado en `bin/`. Para compilar se utiliza el `Makefile` del
proyecto.

Los archivos `.cpp` nuevos deben añadirse dentro de `src/`.
