# Manual de usuario

## Inicio

Gatochi es un juego de cuidado de un gato. El jugador debe atender sus
necesidades para mantenerlo feliz y saludable.

## Acciones principales

- Alimentar al gato cuando tenga hambre.
- Jugar con el gato para mantenerlo activo y feliz.
- Dejarlo dormir para que descanse.
- Limpiar el arenero y llevarlo al veterinario cuando sea necesario.
